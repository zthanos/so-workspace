# Solution Outline Review Rules

## Evaluation checks
- Missing coverage
- Scope creep
- Template violation
- Diagram mismatch
- Assumption leakage
- Terminology mismatch

## Final review checks
- Every requirement is addressed directly or indirectly
- No unsupported scope is introduced
- Open points remain open unless already resolved in source artifacts
- Terminology remains consistent across inventory, objectives, diagrams, and solution outline
